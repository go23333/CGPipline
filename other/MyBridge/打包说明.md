# MyBridge 打包说明（基于 `pack.py`）

本文档根据当前仓库的 `pack.py` 整理，描述 **如何构建可运行目录版程序**、**生成 Inno Setup 安装包**、以及 **上传安装包到更新服务器**。

---

## 环境要求

- **Python**：建议使用项目 `Readme.md` 所述版本（当前为 3.11）。
- **依赖**：
  - 运行/开发依赖：按项目要求安装（通常是 `requirements.txt`）。
  - 打包依赖：需要 `PyInstaller`（`pack.py` 中直接调用 `PyInstaller.__main__`）。
- **Inno Setup 6**（可选，仅当要打安装包）：
  - `pack.py` 默认路径为：
    - `C:\Program Files (x86)\Inno Setup 6\ISCC.exe`
  - 若你本机路径不同，需要改 `pack.py` 里的 `iscc_exe`。
- **网络/服务器**（可选，仅当要上传）：
  - 上传地址在 `pack.py` 中写死为：`http://192.168.3.20:5050`

---

## 版本号来源（非常关键）

`pack.py` 的版本号来自 `Readme.md` 中以 `## v` 开头的行，例如：

- `## v0.3.2.16`

代码逻辑会遍历所有行并不断覆盖，最终取 **最后一次出现的 `## v...`** 作为版本号。

---

## 打包产物概览

`pack.py` 会在项目根目录生成/使用这些路径：

- **程序目录（PyInstaller onedir）**：`dist/MyBridge/`
  - 由 `PyInstaller` 构建生成
  - 构建后会额外复制：`scripts/` → `dist/MyBridge/scripts`
- **安装包输出**：`dist/MyBridge.exe`
  - 这是 Inno Setup 编译脚本后的输出文件路径（用于上传的也是这个）
- **临时文件**（执行结束会清理）：
  - `version_info.txt`
  - `installer_pack.iss`
  - `MyBridge.spec`
  - `build/`
  - 注意：`dist/` **不会**在最后的 `clean()` 中删除，但每次运行脚本一开始会先删除旧的 `dist/`。

---

## 1）构建可运行程序目录（PyInstaller）

在项目根目录执行（PowerShell / CMD 均可）：

```bash
python pack.py -build
```

### Debug 模式（显示控制台窗口）

```bash
python pack.py -build -debug
```

### 构建参数（来自 `pack.py`）

等价于执行 PyInstaller：

- 入口：`main.py`
- 名称：`MyBridge`
- 图标：`app/resource/image/icon.png`
- 生成版本信息：`--version-file=version_info.txt`
- 非 Debug 时使用 `--windowed`（GUI，无控制台）
- 构建完成后复制：`scripts/` → `dist/MyBridge/scripts`

---

## 2）生成安装包（Inno Setup）

前置：必须先完成 **-build**，确保存在 `dist/MyBridge/`。

执行：

```bash
python pack.py -installer
```

### 生成过程说明

- 读取模板：`other/installer_template.iss`
- 在模板最前面插入一行版本定义：
  - `#define MyAppVersion "<版本号>"`
- 生成脚本：`installer_pack.iss`
- 调用 Inno Setup 编译器：
  - `ISCC.exe installer_pack.iss`

最终安装包文件路径按脚本约定为：

- `dist/MyBridge.exe`

---

## 3）上传安装包到更新服务器

前置：确保安装包文件存在：

- `dist/MyBridge.exe`

执行：

```bash
python pack.py -upload
```

上传 URL（由脚本拼接）：

- `http://192.168.3.20:5050/update/upload/<版本号>`

上传方式：HTTP `POST`（multipart form），字段名为 `file`。

---

## 推荐的完整发布流程（一次发版）

按顺序执行：

```bash
python pack.py -build
python pack.py -installer
python pack.py -upload
```

如果你希望“一个命令跑完”，`pack.py` 支持在一次运行里组合参数：

```bash
python pack.py -build -installer -upload
```

---

## 常见问题排查

- **找不到 ISCC.exe**：
  - 安装 Inno Setup 6，或修改 `pack.py` 的 `iscc_exe` 为你本机路径。
- **版本号不对**：
  - 检查 `Readme.md` 是否在末尾仍有旧的 `## v...` 行；脚本取的是“最后出现的版本号”。
- **安装包生成失败提示“打包的程序文件不存在”**：
  - 说明 `dist/MyBridge/` 不存在；先执行 `python pack.py -build`。
- **上传失败**：
  - 检查是否能访问 `192.168.3.20:5050`，以及服务端是否允许该版本号上传。
